## Provider facts from the U1 spike (authoritative; full report in `android/docs/provider-spike.md`, fixtures in `android/core/network/src/test/resources/fixtures/`, name lists in `android/core/consolidation/src/test/resources/names/`)
- `max_connections` = 1; numeric fields arrive as strings (lenient decoding). allowed formats: m3u8, ts, rtmp. Default live format `.ts`; HLS is a 8–12 s segment, ~60 s window option.
- server_info.timezone = Europe/Amsterdam; `timestamp_now` is true UTC epoch.
- Sizes: get_live_streams 22k items/8 MB; get_vod_streams 45k items/18 MB (2.5 MB gzip); get_series 11k/11 MB. → eager per-type sync with streaming decode + batched inserts; per-category is fallback only. Always send `Accept-Encoding: gzip`.
- VOD list field is `tmdb` (string or int); 87.5% coverage; get_vod_info does not fill gaps. Same tmdb shared by up to 14 items. Reject tmdb merges when years differ (sports items reuse a film's tmdb). Name prefixes mix language (`EN`, `IN-xx`), platform (`NF`, `AMZ`, `D+`, `TOP`, `SOC`) and quality (`4K-`); use the category name for language when the prefix is a platform code.
- Archive: 384 channels (327×3 d, 57×7 d). xmltv.php = 86 MB raw / 16.6 MB gzip, covers only ~−24 h … +50 h, offsets `+0100` → `get_simple_data_table` backfill required for older archive days (it reaches ~4.6 d back).
- get_short_epg / get_simple_data_table: `start`/`end` strings are server-local (Amsterdam) wall time; `start_timestamp`/`stop_timestamp` are WRONG (local time treated as UTC → 1 h late). Parse the strings in server timezone; ignore *_timestamp; titles/descriptions are base64. `get_simple_date_table` (misspelled) is not a real action.
- EPG mapping: only 12% of API channels have epg_channel_id; playlist tvg-id usually differs. Match on either key case-insensitively; 1,392 playlist stream ids are absent from get_live_streams (merged 24/7 channels) — tolerate.
- Live `.ts`: 302 redirect to a different host with a tokenised path (credentials stay in path), then 200 video/mp2t, no Content-Length; TTFB 0.4–1.1 s (2.6 s cold). Redactor must cover redirect targets/token paths too.
- Connection release: immediate (new stream OK at 0 s). Connection-limit status code not observed.
- Catch-up: both path-style and timeshift.php work identically; start time interpreted in server timezone; Content-Length present and Range → 206, so native seeking works (Accept-Ranges header is non-standard — don't rely on it). TS sync byte at offset 172. Outside archive → 404. VOD supports Range.
- Non-existent live/movie id → 405 (Cloudflare): treat as stream error (failover).
