### Changes since 0.1.8 (2026-11-22–25, committed 2026-11-25)

- **Guide import and refresh:** an indexed programme-overlap query, cancellation propagation and diagnostic logging improve the import path; an open TV or mobile guide reloads after a committed import. The earlier `.90` timeout and database writer stall were observed, but the optimized query was not conclusively identified as the stalled writer. A guide import and visible listings were verified on a device after the fix; `.226` later logged a successful manual import. Scheduled daily guide work requires an idle device and unmetered network, so it is not guaranteed at a fixed time.
- **Catch-up playback:** privacy-safe `PlaybackDiag` events record buffering and playback progress. The stall watchdog gets a fresh six-second progress window after buffering ends; retry uses the selected seek position. For ongoing restarted programmes, the app-wired experimental strategy rebuilds the timeshift URL near the selected minute and seeks the residual; completed catch-up retains native seeking. A user confirmed one restart seek landed correctly, but buffering and dropped frames were still observed and provider-wide effectiveness is unproven.
